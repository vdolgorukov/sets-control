# Контрольная: элементы, подмножества, P(X), |X|

Генератор контрольных к упражнениям 1.1–1.5 и 1.24–1.26 сборника «Логика: сборник упражнений» (В. В. Долгоруков, НИУ ВШЭ).
Один самодостаточный файл `index.html` без внешних зависимостей.

- Вариант задаётся seed: тот же seed при тех же параметрах всегда даёт тот же вариант.
- Проверка только после «Сдать и проверить», в конце — сводка по типичным ошибкам.
- «Экспорт в LaTeX»: условие и лист ответов (`\answersfalse` / `\answerstrue`); верные пункты помечены `\item[v]`.
- «Печать» — вариант без подсказок.

Ядро и генератор те же, что в тренажёре https://vdolgorukov.github.io/sets-trainer/.
Автотесты: кнопка «Самопроверка», `SetCore.selfTest()` в консоли или `node tests/run.js`.
